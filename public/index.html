Laboratorio mercedev.

Bienvenido a mi base de operaciones. Un entorno web híbrido diseñado bajo la filosofía DevSecOps para alojar mi Biblioteca técnica y los cuadernillos de Art de Coté.

Activos de Conocimiento

La Biblioteca

Documentación técnica definitiva y arquitectura de software. Trazabilidad de decisiones estructurada en Desafío, Maniobra y Aprendizaje.

Art de Coté

Cuadernillos divulgativos y exploración técnica colateral. El resultado documentado de las desviaciones útiles ocurridas durante el desarrollo principal.

Sistema Merci

Motor de automatización local escrito en Python. Orquesta la auditoría estricta pre-commit, optimiza la ingesta multimedia y sella la seguridad Shift-Left.

Infraestructura Híbrida

Núcleo Estático

Esta portada y la Biblioteca son servidas directamente por Nginx. Arquitectura SASS 7-1, metodología BEM y cero dependencias para garantizar una puntuación 100/100 en Core Web Vitals.

Capa Dinámica

Art de Coté y el catálogo operan sobre un CMS encapsulado bajo proxy inverso. Una integración limpia que separa el código inmutable del control de versiones del estado de la base de datos.
