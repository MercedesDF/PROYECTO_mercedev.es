Bienvenido a Merci Boilerplate.

Tu nueva base de operaciones. Un entorno web híbrido, seguro desde el diseño (Shift-Left) y ultrarrápido, creado con criterio arquitectónico por mercedev.es.

Características del Motor

Seguridad Activa

Auditoría estática automatizada (Merci Audit) previa a cada commit.

Aislamiento Dinámico

WordPress encapsulado e invulnerable, sirviendo datos sin ensuciar la raíz.

Rendimiento Puro

CSS compilado desde SASS 7-1, metodología BEM y 0 dependencias innecesarias.

Demostración de Arquitectura

Núcleo Estático

Estás viendo el núcleo estático. Servido directamente por Nginx, es indestructible y garantiza una puntuación perfecta en Core Web Vitals.

Capa Dinámica (WP)

El menú superior define las rutas que serán gestionadas por el CMS. Una vez configuradas las categorías en WordPress, consumirán los estilos SASS nativamente.
