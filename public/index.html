La Evolución

La web clásica ha muerto bajo el peso de frameworks gigantescos. Este proyecto nace como una tesis arquitectónica: demostrar que es posible construir un sistema de automatización y publicación masiva sin inyectar ni una sola dependencia en el navegador del usuario final.

Estado de la Infraestructura

Actualmente, mercedev.es se sostiene sobre una arquitectura de 3 capas aisladas mediante proxy inverso (Nginx), gobernadas por más de 25 herramientas DevSecOps escritas en Vanilla Python:

  • Capa Estática: HTML5 semántico + SASS BEM + Vanilla JS (100/100 Core Web Vitals).
  • Capa Dinámica: WordPress Headless acoplado mediante enlaces simbólicos y APIs restrictivas.
  • Capa IA (Hybrid Stack): Orquestación Autónoma mediante Ollama (Local) y Gemini Flash (Cloud) con resiliencia Fail-Gracefully.
