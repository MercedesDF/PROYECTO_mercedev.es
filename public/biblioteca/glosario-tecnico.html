Glosario Técnico DevSecOps & Arquitectura

Este glosario contiene actualmente 6 términos y expresiones informáticas de nivel intermedio y avanzado, extraídos del análisis de las bitácoras del proyecto.

Índice Alfabético

Registro de Decisiones Arquitectónicas (ADR)

Inglés: Architecture Decision Record Español: Registro de Decisiones Arquitectónicas

Definición: Documentación formal que registra la toma de decisiones cruciales en el diseño y arquitectura de un sistema, incluyendo las razones detrás de cada decisión, los impactos potenciales y los compromisos tomados.

Apariciones en Bitácoras: - bitacora-mercedev-epic-02.md: L606 - bitacora-mercedev-epic-03.md: L45

Registro de Cambios Inteligente Artificial (AI-Changelog)

Inglés: Artificial Intelligence Change Log Español: Registro de Cambios Inteligente Artificial

Definición: Registro que documenta las modificaciones realizadas en el código o arquitectura relacionada con la inteligencia artificial, incluyendo detalles sobre los cambios, sus motivos y su impacto en el sistema.

Apariciones en Bitácoras: - bitacora-mercedev-epic-02.md: L988 - bitacora-mercedev-epic-06.md: L68

JavaScript Asíncrono y XML (AJAX)

Inglés: Asynchronous JavaScript and XML Español: JavaScript Asíncrono y XML

Definición: Tecnología que permite actualizar partes de una página web sin tener que recargar la página completa, mediante el intercambio de datos con un servidor en segundo plano usando JavaScript.

Apariciones en Bitácoras: - bitacora-mercedev-epic-01.md: L3315

Aplicaciones Web Acessibles (ARIA)

Inglés: Accessible Rich Internet Applications Español: Aplicaciones Web Acessibles

Definición: Conjunto de prácticas y tecnologías utilizadas para crear contenido web que sea accesible a personas con discapacidades visuales, auditivas o motoras.

Apariciones en Bitácoras: - bitacora-mercedev-epic-01.md: L2685

Árbol Sintáctico Abstracto (AST)

Inglés: Abstract Syntax Tree Español: Árbol Sintáctico Abstracto

Definición: Representación estructurada de un programa fuente en un formato que puede ser analizado y procesado por sistemas de análisis estáticos o herramientas de compilación.

Apariciones en Bitácoras: - bitacora-mercedev-epic-06.md: L169

Pruebas de Seguridad de Aplicaciones (ATS)

Inglés: Application Security Testing Español: Pruebas de Seguridad de Aplicaciones

Definición: Proceso sistemático y automatizado de identificar, evaluar y mitigar vulnerabilidades de seguridad en aplicaciones software.

Apariciones en Bitácoras: - bitacora-mercedev-epic-01.md: L232
