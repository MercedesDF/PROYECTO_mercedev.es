Glosario Técnico DevSecOps & Arquitectura

Estado del Documento: Glosario vivo y autónomo. Un agente rastrea continuamente las bitácoras para extraer y definir nueva terminología DevSecOps. Versión de control: 12 términos consolidados (Última actualización de datos: 2026-05-24 19:25).

Índice Alfabético

ADR

Inglés: Architecture Decision Record | Español: Registro de Decisiones Arquitectónicas

Definición: Documentación formal que registra la toma de decisiones cruciales en el diseño y arquitectura de un sistema, incluyendo las razones detrás de cada decisión, los impactos potenciales y los compromisos tomados.

💡 Merci Explica: Es como el diario o acta de decisiones del proyecto. Apuntamos el 'porqué' elegimos una tecnología o camino para no olvidarlo meses después.

Apariciones en Bitácoras: - bitacora-mercedev-epic-02.md: L606 - bitacora-mercedev-epic-03.md: L45

AI-Changelog

Inglés: Artificial Intelligence Change Log | Español: Registro de Cambios Inteligente Artificial

Definición: Registro que documenta las modificaciones realizadas en el código o arquitectura relacionada con la inteligencia artificial, incluyendo detalles sobre los cambios, sus motivos y su impacto en el sistema.

💡 Merci Explica: Un historial específico donde anotamos qué le hemos enseñado o modificado a la Inteligencia Artificial del proyecto.

Apariciones en Bitácoras: - bitacora-mercedev-epic-02.md: L988 - bitacora-mercedev-epic-06.md: L130

AJAX

Inglés: Asynchronous JavaScript and XML | Español: JavaScript Asíncrono y XML

Definición: Tecnología que permite actualizar partes de una página web sin tener que recargar la página completa, mediante el intercambio de datos con un servidor en segundo plano usando JavaScript.

💡 Merci Explica: El mecanismo que permite que una página web cargue o envíe datos en segundo plano sin que tengas que actualizar la pestaña.

Apariciones en Bitácoras: - bitacora-mercedev-epic-01.md: L3315

ARIA

Inglés: Accessible Rich Internet Applications | Español: Aplicaciones Web Acessibles

Definición: Conjunto de prácticas y tecnologías utilizadas para crear contenido web que sea accesible a personas con discapacidades visuales, auditivas o motoras.

💡 Merci Explica: Etiquetas invisibles que le ponemos al código para que los lectores de pantalla puedan explicarle la web a las personas con discapacidades visuales.

Apariciones en Bitácoras: - bitacora-mercedev-epic-01.md: L2685

AST

Inglés: Abstract Syntax Tree | Español: Árbol Sintáctico Abstracto

Definición: Representación estructurada de un programa fuente en un formato que puede ser analizado y procesado por sistemas de análisis estáticos o herramientas de compilación.

💡 Merci Explica: Es como un mapa mental que usan los compiladores para entender y desglosar el código de programación que escribimos.

Apariciones en Bitácoras: - bitacora-mercedev-epic-06.md: L231

ATS

Inglés: Applicant Tracking System | Español: Sistema de Seguimiento de Candidatos

Definición: Software corporativo utilizado por los departamentos de recursos humanos para filtrar, organizar y escanear currículums automáticamente durante los procesos de selección.

💡 Merci Explica: Los robots de Recursos Humanos que leen los currículums antes de que lleguen a una persona real.

Apariciones en Bitácoras: - bitacora-mercedev-epic-01.md: L232

BEM

Inglés: Block Element Modifier | Español: Bloque Elemento Modificador

Definición: Método de nomenclatura para clases CSS que ayuda a mantener el código limpio, legible y reutilizable al dividir los elementos en bloques, elementos y modificadores.

💡 Merci Explica: Sistema de nomenclatura para clases CSS que facilita la organización y mantenimiento del código.

Apariciones en Bitácoras: - bitacora-mercedev-epic-01.md: L105 - bitacora-mercedev-epic-03.md: L741 - bitacora-mercedev-epic-04.md: L98 - bitacora-mercedev-epic-05.md: L62

BOM

Inglés: Browser Object Model | Español: Modelo de Objeto del Navegador

Definición: Interfaz proporcionada por los navegadores web que permite a las aplicaciones JavaScript interactuar con el contenido y la funcionalidad del navegador.

💡 Merci Explica: Conjunto de objetos y métodos que permiten a los scripts JavaScript controlar y manipular el comportamiento del navegador.

Apariciones en Bitácoras: - bitacora-mercedev-epic-01.md: L1648

CI

Inglés: Continuous Integration | Español: Integración Continua

Definición: Práctica de desarrollo en la que el código fuente se integra automáticamente a una rama principal o versión estable con frecuencia, generalmente varias veces al día.

💡 Merci Explica: Proceso automatizado que permite combinar cambios de múltiples desarrolladores y detectar problemas de incompatibilidad temprano.

Apariciones en Bitácoras: - bitacora-mercedev-epic-01.md: L206 - bitacora-mercedev-epic-02.md: L484 - bitacora-mercedev-epic-03.md: L115 - bitacora-mercedev-epic-04.md: L120

CLI-First

Inglés: Command Line Interface - First | Español: Interfaz de Línea de Comandos - Primero

Definición: Enfoque en el desarrollo y diseño de aplicaciones que prioritizan la interacción a través de interfaces de línea de comandos, enfocándose en facilitar la ejecución de tareas desde un terminal o consola.

💡 Merci Explica: Método orientado al usuario final que se centra en proporcionar herramientas y utilidades accesibles a través de comandos directos en el sistema operativo.

Apariciones en Bitácoras: - bitacora-mercedev-epic-01.md: L1237 - bitacora-mercedev-epic-02.md: L1086

CLS

Inglés: Clear Screen | Español: Limpiar Pantalla

Definición: Comando o función que limpia la pantalla actual, eliminando todos los caracteres visibles y preparando la superficie para una nueva salida.

💡 Merci Explica: Instrucción utilizada en interfaces de línea de comandos para limpiar el contenido visible del terminal.

Apariciones en Bitácoras: - bitacora-mercedev-epic-01.md: L160

CMS

Inglés: Content Management System | Español: Sistema de Gestión de Contenido

Definición: Software que facilita la creación, edición y publicación de contenido en una web o aplicación. Permite a los usuarios administrar el contenido sin necesidad de conocimientos técnicos avanzados.

💡 Merci Explica: Plataforma que permite a los sitios web y aplicaciones gestionar su contenido de manera eficiente y rápida.
