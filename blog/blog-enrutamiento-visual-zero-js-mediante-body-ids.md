## El Desafío (Síntoma)
En arquitecturas SSG, añadir la clase `.active` a los enlaces activos era imposible sin JavaScript. La latencia y el peso del DOM aumentaban.

## La Maniobra (Lógica)
Usamos CSS nativo y Python para inyectar un ID único en `<body>`. Posteriormente, combinamos selectores SASS para resaltar automáticamente los enlaces activos.
