Cuando la telemetría colapsa, el ecosistema digital se ve amenazado con una falta de interactividad visual. El reto principal era enriquecer la experiencia del usuario sin sacrificar el rendimiento ni la accesibilidad.

La solución arquitectónica fue adoptar una política estricta de *Zero-JS*. Todas las animaciones y microinteracciones se delegaron a transiciones nativas de CSS y variables SASS, asegurando que no penalizaran el Tiempo de Bloqueo Total (TBT). 

Además, se ajustó la paleta de colores para cumplir con los estándares WCAG AA/AAA, como el tono malva en avisos de la tienda, que alcanza un ratio superior a 7:1.

### 💡 En resumen:
La delegación de las animaciones a CSS puro es como contratar a un malabarista profesional. 

El navegador permanece libre para atender los pedidos del usuario al instante (0ms de latencia), mientras la interfaz web luce dinámica y accesible.
