Para validar empíricamente nuestras defensas DevSecOps, creamos un Chaos Monkey impulsado por IA local (Qwen 2.5 Coder). El agente ataca nuestro código inyectando vulnerabilidades (como estilos en línea o scripts XSS) y luego lanza a merci-audit.py para evaluar si el linter logra detenerlo. Durante el proceso aprendimos dos lecciones críticas: el mecanismo de Rollback (git restore) debe estar siempre dentro de un bloque try...finally para sobrevivir a interrupciones manuales (Ctrl+C) y no dejar el código envenenado, y las Regex del auditor deben ser lo suficientemente robustas para cazar etiquetas script maliciosas sin generar falsos positivos con datos estructurados JSON-LD. Demostramos que nuestras barreras Shift-Left son infranqueables.
