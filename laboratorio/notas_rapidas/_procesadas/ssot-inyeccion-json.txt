Para el agente SSOT, nos dimos cuenta de que pedirle a la IA que reescriba un archivo de 200 líneas del Roadmap solo para poner una 'X' es un desperdicio de tokens y causa alucinaciones (mutilaba el archivo truncándolo). Aplicamos un patrón de 'Decisión vs Ejecución' (Targeted Payload Extraction). Ahora Python (la Mano) extrae las tareas pendientes mediante regex, se las pasa a la IA (el Cerebro), la IA solo devuelve un array JSON con las tareas completadas, y Python hace un .replace() matemático en el archivo físico. El uso de tokens bajó un 90%, es rapidísimo y hay 0% de riesgo de romper el documento Markdown.
